AMElleventh - Next.js / React with EmailJS

1. Follow README.md to create your EmailJS service and template.
   Copy .env.example to .env.local and fill in:
   NEXT_PUBLIC_EMAILJS_SERVICE_ID
   NEXT_PUBLIC_EMAILJS_TEMPLATE_ID
   NEXT_PUBLIC_EMAILJS_PUBLIC_KEY

2. In this folder, run:
   npm install
   npm run build

3. Upload the CONTENTS of the generated out folder to the site's root,
   including the _next folder and all other exported files.
   Cloudflare Pages Direct Upload: upload the out folder.
   Cloudflare Pages connected build: command npm run build, output out;
   set the same three environment variables in the build settings.
   The root index.html is the original reference, not the migrated build.
   Do not upload the project source folder or .env.local.

4. Point amelleventh.com (and www) to the site and enable HTTPS.
   Rebuild and upload again whenever EmailJS settings change.

5. Submit a test enquiry and confirm delivery to engage@amelleventh.com.
   Check every field and the reply address. Live delivery has not been
   verified without your EmailJS credentials.

6. Check the page and gold Pi cursor on desktop, and the menu and WhatsApp
   links on a phone. Check the link preview by sharing the URL to yourself.
